# SIH26117 — Sovereign AI Workbench

> **Smart India Hackathon 2026 | Problem Statement 26117**

A sovereign, on-premise agentic AI workbench designed for confidential industrial knowledge work using open-weight multimodal AI.

The system is intended to enable organizations to perform AI-assisted tasks such as document analysis, planning, tool execution, multimodal understanding, knowledge retrieval, and deliverable generation while keeping sensitive workloads within the organization's controlled environment.

## 🎯 Problem Statement

**Sovereign On-Premise Agentic AI Workbench using Open-Weight Multimodal LLMs for Confidential Industrial Work**

**Organization:** Mangalore Refinery and Petrochemicals Limited (MRPL)
**Category:** Software
**Theme:** Smart Automation

## 🏗️ Project Direction

The project is being developed as a modular AI workbench with:

* Agent Runtime
* Model Routing
* Tool Runtime
* Multimodal Processing
* Local Knowledge Base
* Sandboxed Execution
* Deliverable Generation
* Security & Auditability

The architecture is designed to remain model-agnostic and deployment-oriented.
